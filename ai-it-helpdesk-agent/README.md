# AI IT Helpdesk Agent — IBM Internship Project

An enterprise-grade, autonomous Tier-1 IT Support Agent engineered with **LangChain**, **LangGraph**, **Python**, **SQLite**, and **Streamlit**. The system operates on a stateful **Perceive ➔ Plan ➔ Act ➔ Iterate** ReAct loop, utilizing a decoupled architecture adhering to **Model Context Protocol (MCP)** principles for clean, tool-augmented problem resolution.

## 2. Five Actionable IT Tools (MCP Decoupled)

| # | Tool Identifier | MCP Schema / Function | Purpose |
|---|---|---|---|
| **1** | `query_helpdesk_db` | `tools/db_tool.py` | Read-only SQL executor querying `employees`, `it_tickets`, and `system_logs` in `helpdesk.db`. |
| **2** | `search_knowledge_base` | `tools/rag_tool.py` | Semantic search over internal IT SOPs, VPN configuration, BitLocker, and SLA policies. |
| **3** | `reset_employee_password` | `tools/password_reset_tool.py` | Validates active employee credentials, generates 14-character high-entropy OTP, and logs security audit. |
| **4** | `check_system_status` | `tools/system_status_tool.py` | Queries real-time endpoint latency and incident advisories across VPN, Email, Active Directory, DB, and Ticketing. |
| **5** | `escalate_ticket` | `tools/ticket_escalation_tool.py` | Dispatches structured Jira/ServiceNow JSON payloads with priority (P1-P4) and inserts record into `it_tickets`. |

## 4. Step-by-Step Local Execution Instructions

### Step 1: Clone or Open the Project
Ensure you have **Python 3.10+** installed:
```bash
python3 --version
```

### Step 2: Create and Activate Virtual Environment
```bash
# macOS/Linux
python3 -m venv venv
source venv/bin/activate

# Windows (Command Prompt / PowerShell)
python -m venv venv
.\venv\Scripts\activate
```

### Step 3: Install Required Dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Step 4: Initialize the SQLite Database
Run the pre-load script to generate `helpdesk.db` populated with realistic enterprise records:
```bash
python3 setup_db.py
```
*Expected Output:*
```
[*] Initializing SQLite database at: .../helpdesk.db
[✓] Successfully populated 'helpdesk.db' with:
    - 8 Employee profiles
    - 5 Historical IT Tickets
    - 5 System Audit Log entries
```

### Step 5: (Optional) Set Cloud Model API Keys
You can run the agent in **Autonomous ReAct Engine (Local)** mode without any API keys, or supply an API key for Groq, OpenAI, or Gemini in `.env` or in the Streamlit sidebar:
```bash
# In .env file or terminal:
export GROQ_API_KEY="your-groq-api-key"
# or
export OPENAI_API_KEY="your-openai-api-key"
# or
export GEMINI_API_KEY="your-gemini-api-key"
```

### Step 6: Launch the Streamlit Interactive Dashboard
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`.

## 5. Sample Test Scenarios for Demonstration

1. **VPN Connectivity Incident:**
   - Prompt: *"My name is Michael Scott and I cannot connect to GlobalProtect VPN. It gives Error 503."*
   - ReAct Cycle:
     - **Perceive:** Identifies employee (Michael Scott) and intent (`vpn_issue`).
     - **Plan:** Look up profile in DB, check GlobalProtect KB SOP, and ping VPN gateway status.
     - **Act:** Invokes `query_helpdesk_db`, `search_knowledge_base`, and `check_system_status`.
     - **Iterate:** Confirms VPN gateway is operational, diagnoses client-side DNS/captive portal issue, and generates step-by-step resolution tailored to employee's Windows 11 Enterprise OS.

2. **Self-Service Password Reset:**
   - Prompt: *"Reset password for pam.beesly@company.com - my account is locked."*
   - ReAct Cycle:
     - **Perceive:** Identifies email `pam.beesly@company.com` and intent (`password_reset`).
     - **Act:** Invokes `reset_employee_password`. Validates employee is active, generates temporary password with 15-minute expiration, and logs audit event to `system_logs`.
     - **Iterate:** Synthesizes SSO sign-in instructions and 14-character complexity requirements.

3. **Hardware Failure & Escalation:**
   - Prompt: *"Dwight Schrute here. My USB-C dock is flashing amber and monitors won't power on."*
   - ReAct Cycle:
     - **Perceive:** Identifies hardware issue and employee.
     - **Act:** Invokes `search_knowledge_base` for docking station reset SOP, then automatically dispatches `escalate_ticket` to Desktop Support with priority `P3-Medium`.
     - **Iterate:** Returns ticket confirmation (`IT-1043`), Jira payload, and 30-second capacitor discharge SOP.

4. **System Outage Query:**
   - Prompt: *"Check system status and active outages."*
   - ReAct Cycle:
     - **Act:** Invokes `check_system_status(service_name='all')`.
     - **Iterate:** Surfaces operational metrics and flags Microsoft 365 Exchange advisory (`EX781290`).

## 6. Model Context Protocol (MCP) Compliance

This project is architected around Model Context Protocol (MCP) standards:
- **Declarative Manifests:** Each tool exports a strict JSON Schema detailing parameter types, descriptions, and required keys.
- **Uniform Protocol Response:** All tool executions return standardized MCP content blocks:
  ```json
  {
    "content": [{"type": "text", "text": "..."}],
    "is_error": false,
    "metadata": { ... }
  }
  ```
- **Decoupled Deciders:** The agent loop reasons solely against tool interfaces without hardcoded logic couplings, allowing drop-in tool extension.
